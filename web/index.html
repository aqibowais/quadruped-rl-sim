Maze

The walker never saw a wall in training. A* plans a route on the maze grid, and each step the walker is pointed at a spot 2.2 m further along it. If it stops making progress for 3 s it shuffles sideways, then carries on. The three simpler pilots run the same maze for comparison.

Learning curves

Evaluation return during training, mean ± 1 sd. SAC ran 1M steps, the tuned PPO 2M. Click a SAC checkpoint tick to watch it.

The first PPO run started with an action standard deviation of 1.0. Torques that large throw the torso past the health limit within a few dozen steps, so episodes ended before anything was learned. The tuned run starts at log σ = −1 and uses separate 256×256 networks, 8 × 1024-step rollouts and minibatches of 256.

Method

Environment

Gymnasium Ant-v4, MuJoCo 3.1.6. 27 observations, 8 torques in [−1, 1], reward = forward velocity + survival bonus − control cost. Episodes end at 1,000 steps or when the torso leaves 0.2–1.0 m.

Training

Stable-Baselines3 2.3, one seed per configuration. SAC: 1M steps, 256×256, 1M buffer, auto entropy, RTX 4060, 2.7 h. PPO: 8 envs, observation and reward normalization, 2M steps on CPU, 35 min. Steering: PPO, 12 envs, 8M steps, 42 min.

Replays

export_web.py and export_nav.py run each checkpoint in MuJoCo with deterministic actions and record body poses, foot contacts and joint torques at 20 Hz. This page plays those recordings back.

Limits

One seed per algorithm, so the SAC/PPO gap is this run's result, not a ranking. No actuator latency, sensor noise or rough terrain. The planner is given the maze layout.
